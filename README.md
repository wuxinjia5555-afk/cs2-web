# DEFUSE 爆破行动 · 网页版 CS2 风格战术射击

浏览器里直接玩的 3D 多人第一人称射击游戏，玩法规则参考 CS2：T / CT 两个阵营、爆破模式（下包 / 拆包）、经济系统、买枪菜单、半场换边、死斗模式、人机机器人，支持联机房间。

> 地图、人物、武器模型、贴图和音效全部由代码程序生成（原创），没有使用任何 Valve / CS2 的素材。

## 功能

- **3 张地图**：沙城（双包点三条路线）、仓库（工业集装箱）、竞技场（对称练枪图）
- **两种模式**：爆破模式（MR8/16/24，半场换边，先赢过半获胜）、死斗（10 分钟 / 40 杀）
- **16 种武器**：Glock、USP-S、P250、沙鹰、MAC-10、MP9、UMP-45、Nova、加利尔、法玛斯、AK-47、M4A4、M4A1-S、鸟狙、AWP、匕首
- **投掷物**：高爆手雷、闪光弹（按朝向致盲）、烟雾弹（遮挡视线，机器人也看不穿）、燃烧瓶 / 燃烧弹（持续伤害，烟雾可灭火）
- **CS 手感**：Source 引擎式移动（加速度、摩擦、空中转向、蹲跳、静步）、移动/跳跃开枪不准、固定可学习的弹道后坐力（压枪）、爆头 ×4、护甲穿透、距离衰减、背刺
- **经济**：开局 $800、胜利 $3250/$3500、连败补偿、击杀奖励（刀 $1500、冲锋枪 $600、AWP $100…）、购买区与购买时间
- **机器人**：三档难度，会买枪、选路线、寻路、听枪声、反应时间 + 瞄准误差 + 压枪、下包、拆包、守点、扔手雷
- **界面**：跟随视角旋转的雷达（显示队友和被发现的敌人）、击杀信息、伤害方向、记分板、MVP、回合结算、观战、聊天、准星自定义
- **联机**：房间码 / 邀请链接加入、机器人自动补位、热身阶段、房主开始比赛

## 手机怎么玩

手机（安卓 / iPhone / 平板）用浏览器打开同一个网址即可，会自动切换成触屏操作，**横屏游玩**：

- 左半屏任意位置按住拖动 = 移动摇杆（推一点点是静步，没有脚步声）
- 右半屏滑动 = 转视角；红色「开火」键按住后可以继续拖动瞄准（左边还有一个开火键）
- 右下：跳、蹲（点一下切换）、换弹、开镜 / 重击 / 轻抛（根据手上的武器变化）
- 靠近炸弹或地上的枪时会出现蓝色「拆弹 / 捡起」键；底部一排是切枪栏和丢弃
- 右上：购买、战绩、聊天、菜单
- 设置里可以调滑屏灵敏度、按钮大小和透明度，开关「辅助瞄准」「自动开火」「陀螺仪瞄准」

安卓进游戏会自动全屏并锁定横屏；iPhone 在 Safari 里点「分享 → 添加到主屏幕」，从桌面图标打开就是全屏。手机默认关闭阴影、降低分辨率以保证流畅，可在设置里调整。

## 在自己电脑上运行

需要 Node.js 18 以上（https://nodejs.org）。

```bash
npm install
npm start
```

然后打开 http://localhost:8080 。Windows 也可以直接双击 `启动服务器.cmd`。

**局域网联机**：服务器启动时会打印类似 `http://192.168.1.23:8080` 的地址，同一个 Wi-Fi 下的朋友在浏览器打开这个地址，进入「联机对战」加入你的房间即可（第一次运行时 Windows 防火墙会询问，选择允许）。

## 部署到公网（Render 免费版）

1. 把本目录上传到一个新的 GitHub 仓库。
2. 登录 https://render.com → **New** → **Blueprint** → 选择这个仓库，Render 会读取 `render.yaml` 自动创建服务。
3. 部署完成后打开 Render 给的地址（如 `https://defuse-fps.onrender.com`），把房间邀请链接发给朋友。

免费实例闲置 15 分钟会休眠，第一次打开需要等 30~60 秒唤醒。

## 目录结构

```
server/server.js        静态网页 + WebSocket 联机 + 房间大厅
server/ws.js            零依赖 WebSocket 实现
public/index.html       页面与 HUD
public/js/main.js       主菜单 / 大厅
public/js/shared/       服务端和浏览器共用的逻辑（离线人机就是在浏览器里跑同一份房间逻辑）
  room.js               回合、经济、伤害、炸弹、投掷物、掉落
  bot.js / nav.js       机器人 AI 与 A* 寻路
  physics.js            碰撞、移动、射线、命中盒
  weapons.js            武器数据与后坐力
  maps.js               地图定义（用"挖掘式"构建器，新增地图很方便）
public/js/client/       3D 渲染、第一人称武器、特效、音效、HUD
tools/sim.js            纯机器人无头对局测试：node tools/sim.js sandstorm bomb 12
```

## 加一张新地图

在 `public/js/shared/maps.js` 的 `MAPS` 里新增一项：默认全是墙，用 `floor()` 挖出地面、`ramp()` 做坡道、`objs()` 摆箱子和沙袋、`site()` 标包点、`spawn()` 设出生点。改完运行 `node tools/sim.js 地图名` 检查出生点到包点是否连通、机器人能不能正常打完一局。
