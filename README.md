# DEFUSE 爆破行动 · 网页版 CS2 风格战术射击

浏览器里直接玩的 3D 多人第一人称射击游戏，玩法规则参考 CS2：T / CT 两个阵营、爆破模式（下包 / 拆包）、经济系统、买枪菜单、半场换边、死斗模式、人机机器人，支持联机房间。

> 地图、人物、武器模型、贴图全部由代码程序生成（原创）；音效大部分是程序合成的，枪声用的是公有领域（CC0）的真实录音（[The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library)，见 `public/sfx/README.txt`）。没有使用任何 Valve / CS2 的素材。

## 功能

- **5 张地图 + 靶场**：沙二（Dust II 布局）、荒漠迷城（Mirage 布局，有地下通道和梯子）、沙城、仓库、竞技场；靶场可以打固定 / 移动 / 下蹲假人练枪
- **三种玩法**：爆破模式（MR8/16/24，半场换边，先赢过半获胜）、死斗（击杀补满子弹，死亡位置掉血包）、靶场
- **16 种武器**：Glock、USP-S、P250、沙鹰、MAC-10、MP9、UMP-45、Nova、加利尔、法玛斯、AK-47、M4A4、M4A1-S、鸟狙、AWP、匕首
- **投掷物**：高爆手雷、闪光弹（按朝向致盲）、烟雾弹（遮挡视线，机器人也看不穿）、燃烧瓶 / 燃烧弹（持续伤害，烟雾可灭火）
- **第一人称动作**：所有武器都是带手指的手 + 高精度模型；切枪会拉栓 / 拉套筒，换弹有卸弹匣、装弹匣、再拉栓的全套动作，AWP 和鸟狙每开一枪拉一次栓，Nova 每开一枪上一次膛
- **武器**：CS2 的 34 把枪基本都有（手枪 10、冲锋枪 7、霰弹枪 4、机枪 2、步枪 7、狙击枪 4），每把有自己的模型、握法、切枪和换弹动作；主界面的「配装」里选每个阵营带哪些枪进对局
- **刀皮肤**：蝴蝶刀、爪子刀、M9 刺刀、剥皮小刀、天御刀、影刃、威龙之刃，各有自己的切刀和检视动作（后三把是反握 / 带刀光的花刀）（持刀姿势和 M9 的切刀照 CS:GO 做的）；刀可以丢出去，也能捡起地上的刀
- **CS 手感**：Source 引擎式移动（加速度、摩擦、空中转向、蹲跳、静步）、移动 / 跳跃开枪不准、固定可学习的弹道后坐力（压枪）、爆头 ×4、护甲穿透、距离衰减、背刺
- **经济**：开局 $800、胜利 $3250/$3500、连败补偿、击杀奖励（刀 $1500、冲锋枪 $600、AWP $100…）、购买区与购买时间、买错可以退款
- **机器人**：6 档难度（新手 → 专家），会买枪、选路线、寻路、听枪声、反应时间 + 瞄准误差 + 压枪、下包、拆包、守点、扔手雷
- **界面**：跟随视角旋转的雷达、击杀信息、伤害方向、记分板、MVP、回合结算、观战、聊天、准星自定义、分页设置、帧率上限
- **联机**：房间码 / 邀请链接加入、机器人自动补位、热身阶段、房主开始比赛、断线自动重连；建房间可选回合数和炸弹倒计时（40 / 45 / 60 秒）
- **账号**：注册 / 登录后设置（手机按键布局、灵敏度、键位）存在账号里，换设备登录就能用；联机打比赛挣金币（击杀、下包拆包、赢回合、打完整场，每天上限 800）、刀皮肤解锁（每把 1599 金币）、好友（搜索、添加、互送金币和皮肤）、开发者模式（要密码）

## 手机怎么玩

手机（安卓 / iPhone / 平板）用浏览器打开同一个网址即可，会自动切换成触屏操作，**横屏游玩**：

- 左半屏任意位置按住拖动 = 移动摇杆（推一点点是静步，没有脚步声）
- 右半屏滑动 = 转视角；红色「开火」键按住后可以继续拖动瞄准（左边还有一个开火键）
- 右下：跳、蹲（点一下切换）、换弹、开镜 / 重击 / 轻抛（根据手上的武器变化）
- 靠近炸弹或地上的枪时会出现蓝色「拆弹 / 捡起」键；底部一排是切枪栏和丢弃
- 右上：购买、战绩、聊天、菜单
- 设置里可以调滑屏灵敏度、按钮大小和透明度，开关「辅助瞄准」「自动开火」「陀螺仪瞄准」
- 设置里还能切换固定摇杆、开启「松手急停」，以及自定义每个按键的位置和大小（登录账号后会同步到别的设备）

安卓进游戏会自动全屏并锁定横屏；iPhone 在 Safari 里点「分享 → 添加到主屏幕」，从桌面图标打开就是全屏。手机默认关闭阴影、降低分辨率以保证流畅，可在设置里调整。

## 在自己电脑上运行

需要 Node.js 18 以上（https://nodejs.org）。

```bash
npm install
npm start
```

然后打开 http://localhost:8080 。Windows 也可以直接双击 `启动服务器.cmd`。

**局域网联机**：服务器启动时会打印类似 `http://192.168.1.23:8080` 的地址，同一个 Wi-Fi 下的朋友在浏览器打开这个地址，进入「联机对战」加入你的房间即可（第一次运行时 Windows 防火墙会询问，选择允许）。

## 部署到公网（Render 免费版，固定网址）

Render 免费版的硬盘每次休眠 / 重启都会清空，所以账号数据（设置、金币、皮肤、好友）存在 Upstash 的免费云端 Redis 里。

1. 把本目录上传到一个新的 GitHub 仓库。
2. 登录 https://upstash.com → **Create Database**（Redis，区域选 Singapore）→ 在数据库页面的 **REST API** 里复制 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN`。
3. 登录 https://render.com → **New** → **Blueprint** → 选择这个仓库，Render 会读取 `render.yaml` 并让你填三个值：
   - `DEV_PASSWORD`：开发者模式的密码（服务器启动时只保留加盐哈希）
   - `UPSTASH_REDIS_REST_URL`、`UPSTASH_REDIS_REST_TOKEN`：第 2 步复制的两项
4. 部署完成后打开 Render 给的地址（如 `https://defuse-fps.onrender.com`），把房间邀请链接发给朋友。
5. （可选）把这台电脑上原来的账号搬过去：新服务器刚启动 30 分钟内、还没有任何账号时，运行 `node tools/migrate-accounts.mjs https://你的服务.onrender.com`（只能导一次）。

免费实例闲置 15 分钟会休眠，第一次打开需要等大约 1 分钟唤醒。

部署好以后，每次 `git push` 到 main 分支，Render 都会自动更新，日常流程见 `部署说明.md`。

## 目录结构

```
server/server.js        静态网页 + WebSocket 联机 + 房间大厅
server/ws.js            零依赖 WebSocket 实现
public/index.html       页面与 HUD
public/js/main.js       主菜单 / 大厅
public/js/shared/       服务端和浏览器共用的逻辑（离线人机就是在浏览器里跑同一份房间逻辑）
  room.js               回合、经济、伤害、炸弹、投掷物、掉落
  bot.js / nav.js       机器人 AI 与 A* 寻路
  physics.js            碰撞、移动、射线、命中盒
  weapons.js            武器数据与后坐力
  maps.js               地图定义（用"挖掘式"构建器，新增地图很方便）
public/js/client/       3D 渲染、第一人称武器、特效、音效、HUD
  hdkit.js / hdmodels.js / hdguns.js   武器和手的模型（用代码一个零件一个零件搭的）
  viewmodel.js / vmanims.js            第一人称的摆位和动作（切枪、拉栓、换弹、挥刀）
tools/sim.js            纯机器人无头对局测试：node tools/sim.js sandstorm bomb 12
```

## 加一张新地图

在 `public/js/shared/maps.js` 的 `MAPS` 里新增一项：默认全是墙，用 `floor()` 挖出地面、`ramp()` 做坡道、`objs()` 摆箱子和沙袋、`site()` 标包点、`spawn()` 设出生点。改完运行 `node tools/sim.js 地图名` 检查出生点到包点是否连通、机器人能不能正常打完一局。
